# Acceptance Criteria

## Objective
Establish how each requirement will be validated and the minimum criteria for a feature to be accepted.

## General Criteria
- The requirement is implemented as specified
- Acceptance tests pass successfully
- Related documentation is up to date
- Validations and error messages are correct

## Example Criteria
- Authentication: the user can log in with valid credentials and receives a clear message on error
- Data management: a created record is stored correctly and can be retrieved later
- Security: access to restricted areas is denied for unauthorized users
- Interface: critical pages load within the established time frame
