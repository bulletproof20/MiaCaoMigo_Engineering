# Constraints

## Objective
List the constraints and dependencies that limit the project and influence technical decisions.

## Technical Dependencies
- PostgreSQL as the primary database
- Docker for development and deployment environments
- MkDocs with the Material theme for documentation
- SchemaSpy for data model visualization

## Constraints
- Delivery deadline defined by the academic semester
- Limited hardware resources for testing and deployment
- Compatibility requirements defined by user environments
- Time constraints for implementing additional features

## Operational Considerations
- External integrations only when justified
- Use tools that enable simple maintenance
- Architectural choices that support future extensions
